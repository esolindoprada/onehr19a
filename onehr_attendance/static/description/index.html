OneHR Attendance

Enterprise Time & Attendance for Odoo 19 Community

Canonical Odoo attendance with OneHR shift scheduling, rotation patterns, late/early reconciliation, governed exception evidence, fingerprint CSV import, reconciliation batches, geofence evidence and native Odoo overtime policy metadata.

Operational Control

  • Effective-dated shifts and employee schedules
  • Reusable rotation patterns and night-shift support
  • Draft → Confirmed → Posted readiness workflow
  • Late, early-leave, missing-punch and geofence exceptions
  • CSV device import with idempotent reconciliation

Native-First Architecture

  • Extends hr.attendance; does not create a duplicate attendance master
  • Preserves Odoo 19 native overtime calculation
  • Uses OneHR Core HR employee numbers for controlled imports
  • Optional soft integration with OneHR Assignment, Branch, Time Off and Learning
  • Company-scoped least-privilege security
