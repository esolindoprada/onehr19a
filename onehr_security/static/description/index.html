OneHR Security & Access Control

Effective Roles • SoD • Security Audit • Sensitive-Access Foundation

Enterprise security foundation for OneHR on Odoo 19 Community Edition. Odoo users and groups remain canonical; OneHR adds business roles, effective-dated user-role assignments, segregation-of-duties controls, immutable security evidence and company-scoped governance.

Role & Access Governance

  • Business roles mapped to canonical Odoo groups.
  • Effective-dated user-role assignments.
  • Automatic group reconciliation for start/end dates.
  • Manual groups outside OneHR role management are preserved.
  • Branch-ready extension hooks without a circular dependency.

Compliance & Evidence

  • Warn or deny Segregation-of-Duties policies.
  • Immutable SoD conflict and resolution evidence.
  • Append-only structured high-risk audit ledger.
  • Controlled audit payload anonymization.
  • Explicit sensitive/restricted-data access groups for later domains.

Security Principles

UI visibility never replaces server-side authorization. Privileged role provisioning actions require OneHR Security Manager/Admin checks, raw Odoo group mapping is Security-Admin-only, and technical/security governance groups cannot be indirectly granted through a business role.
