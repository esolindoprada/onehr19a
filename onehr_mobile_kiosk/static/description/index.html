OneHR Mobile Kiosk

Enterprise device-governed attendance and quick HR access for Odoo 19 Community

QR/NFC-ready kiosk UX, optional geolocation/geofence control, encrypted browser offline queue, durable server retry evidence, canonical OneHR Attendance ingestion, soft Time Off requests, device-token rotation, company isolation, analytics and operational audit.

Native-First

  • No duplicate attendance transaction table.
  • Uses hr.attendance.onehr_ingest_interval().
  • Quick Time Off remains a soft integration and runs as the employee user.
  • External public API/webhook ownership stays with onehr_integrations_api.

Security & Resilience

  • Authenticated service user plus hashed device token.
  • Raw device token displayed once; not persisted.
  • Encrypted browser offline queue and durable retry/dead-letter evidence.
  • Face-ready capability without local biometric storage.
