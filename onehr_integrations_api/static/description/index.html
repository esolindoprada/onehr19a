OneHR — Integrations API

REST Endpoints • Webhooks • API Keys • Throttling • Retry Queue • KPI

Lapisan integrasi ringan, aman, terukur untuk menghubungkan OneHR dengan sistem eksternal: payroll, e‑sign, LMS, perangkat absensi, SSO/IdP, hingga portal & mobile app. Tersedia endpoint versi (v1), webhooks dua arah, API key & scope, rate limit, audit log, dan retry queue berbasis jadwal—siap pakai di Odoo 18 Community Edition.

Overview

Modul ini menyediakan integration layer seragam di seluruh ekosistem OneHR. Restful API dan webhooks memudahkan sinkronisasi master & transaksi (karyawan, kehadiran, cuti, rekrutmen, pelatihan, payroll bridge, persetujuan, dokumen) dengan kontrol akses berbasis API key + scope serta pembatasan laju untuk stability. Seluruh permintaan dicatat ke API Log untuk monitoring & audit.

What You Can Integrate

  • Recruitment — kandidat, aplikasi masuk, hasil seleksi.
  • CoreHR — master employee, struktur organisasi, company/branch.
  • Attendance — check‑in/out dari perangkat pihak ketiga.
  • Time Off — pengajuan & persetujuan cuti/sakit.
  • Workflow Approvals — keputusan approve/reject via webhook.
  • Documents & e‑Sign — generate & status dokumen, ttd elektronik.
  • Learning (LMS/xAPI) — progress pelatihan, skor, sertifikat.
  • Payroll Bridge — paket data gaji untuk vendor payroll eksternal.
  • Portal & Mobile Kiosk — konsumsi API dari app/portal karyawan.

Key Features

  • Versioned API (v1) dengan rute rapi & konsisten.
  • API Key & Scope — akses granular per area/endpoint.
  • Rate Limiting — token bucket/leaky bucket per key + rute.
  • Webhooks in/out dengan HMAC signature & timestamp (replay‑safe).
  • Retry Queue — pengiriman ulang webhook yang gagal (cron).
  • Audit & KPI — log request/response, latency, status, error class.
  • OpenAPI/Swagger & Postman Collection siap pakai.
  • CORS & JSON helpers, error schema yang konsisten.
  • Multi‑company/branch aware; rule domain aman untuk data isolasi.

Core Models

  • onehr.api.key — API key, owner (client), scopes, status, last_used.
  • onehr.api.scope — definisi scope → model/route.
  • onehr.webhook — event, target URL, secret, status, terakhir kirim.
  • onehr.api.log — request/response, method, path, latency, result.
  • onehr.api.queue — antrian retry: state, attempts, retry_at.
  • res.config.settings — konfigurasi global API & webhook.

Semua model dilengkapi access control & record rules yang ketat.

Installation

  1. Tambahkan addon ke addons_path Odoo.
  2. Update Apps list, cari OneHR — Integrations API.
  3. Install; dependensi inti (base, onehr_security) akan ikut terpasang.

Configuration

  • Buat API Key dan atur Scope yang diperlukan.
  • Daftarkan Webhook outbound (URL, secret) dan uji kirim.
  • Atur Rate Limit, retry policy, dan CORS di Settings.
  • Ekspos OpenAPI & gunakan Postman Collection untuk QA.

Security

  • Groups: onehr_api_user, onehr_api_admin.
  • Header: X-API-Key; opsional X-Signature HMAC + X-Timestamp.
  • Record Rules multi‑company/branch; masking terbatas untuk PII sensitif.

OpenAPI & Tooling

Health & Monitoring

  • GET /onehr/api/health — basic liveness & readiness.
  • Pivot/Graph KPI: success rate, average latency, error categories.
  • Mail Template untuk pemberitahuan kegagalan webhook.

Performance Notes

  • Index: method, path, status, created_at, api_key_id pada onehr.api.log.
  • Gunakan read_group untuk agregasi; arsipkan log lama berkala.
  • Batasi payload & gunakan pagination (limit/offset).
  • 429 Too Many Requests untuk rate limit—retry dengan backoff.

Compatibility

  • Dirancang untuk Odoo 18 Community Edition.
  • Tanpa fitur EE; semua laporan menggunakan bawaan Graph/Pivot CE.
  • Multi‑company/branch siap; domain & rules disesuaikan otomatis.

Upgrade & Migration

  • Versioning: rute ditandai /v1; perubahan besar akan hadir sebagai /v2.
  • Deprecation: periode transisi & alias rute untuk kompatibilitas.
  • Konvensi penamaan model & field konsisten di seluruh suite OneHR.
