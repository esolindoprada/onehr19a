OneHR Integrations API

REST v1 • API Keys • HMAC Webhooks • Throttling • Retry/Dead Letter • Audit KPI

Enterprise integration boundary for OneHR NEW on Odoo 19 Community Edition. External systems receive a stable API transport while each OneHR business addon remains the owner of its own workflow, security and domain data.

  • Five governed models: API Key, API Scope, Webhook, API Audit Log and Retry Queue.
  • PBKDF2-hashed API secrets and optional HMAC request signing with replay protection.
  • Least-privilege service-user execution: API transport never grants domain authority by itself.
  • Outbound HMAC webhooks with SSRF-aware target validation, bounded backoff and dead-letter evidence.
  • Versioned REST adapters for installed CoreHR, Attendance, Recruitment, Time Off, Workflow, Documents, Learning, Appraisal, Career, Payroll, PnP, SOP, Job Description and Portal services.
  • List/Form/Search on every persistent model plus Kanban/Pivot/Graph where operationally useful.
