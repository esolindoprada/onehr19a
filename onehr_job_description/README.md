# OneHR Job Description

Enterprise Job Description governance for OneHR NEW on Odoo 19 Community Edition.

The addon implements exactly the two product-approved persistent business models:

- `onehr.jd`
- `onehr.jd.version`

Hard dependencies remain exactly `onehr_base` and `onehr_security`.

Core capabilities include position-mapped JD masters, job-family templates, governed
version history, Draft → Review → Approved → Published workflow, KPI/competency/HSE
content, publication evidence, version comparison, coverage analytics, external-source
document capture, and soft model-service contracts for Recruitment, Appraisal,
Career/Succession, Portal and API/BI consumers.

Source acceptance is not runtime acceptance. Windows/Odoo install, upgrade, security,
reporting, scheduler and integration UAT remain mandatory before the addon is frozen.
