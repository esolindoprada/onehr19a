OneHR — Core HR

Native Employee Master • Effective History • Restricted Occupational Health

Enterprise Core HR foundation for Odoo 19 Community Edition. OneHR extends canonical hr.employee, hr.employee.public and hr.version instead of creating a parallel employee master.

Core HR Profile

  • Enterprise employee number and profile completeness.
  • Dependents and emergency contacts.
  • Restricted effective-dated identifier portfolio with masking.
  • Education and prior external employment history.
  • Enterprise engagement classification mapped to native employee_type.
  • Grade and primary-position fields stored on canonical hr.version.

Restricted Occupational Health

  • Work incidents with controlled workflow.
  • Medical assessments with immutable finalization and superseding correction.
  • Minimum-necessary disability/accommodation records.
  • Dedicated Occupational Health group; normal HR/Security Admin do not inherit it.
  • Sensitive reads and changes create structured security-audit evidence.

Architecture Boundaries

Personal document storage, versions, expiry reminders and e-sign belong to onehr_document. Internal employee placement/movement belongs to onehr_assignment. Core HR keeps prior external employment history only. Odoo's native Data Import is used instead of inventing an unregistered import wizard.
